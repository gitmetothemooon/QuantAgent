Objective:
Generate monthly stock recommendations for an Indian retail investor.

Benchmark:
Nifty 50 TRI

Secondary benchmark:
One actively managed large-cap mutual fund.

Evaluation:
Rolling 6-month paper trading.

Primary metric:
Annualized Sharpe ratio.

Secondary metrics:
Maximum drawdown
Win rate
CAGR
Volatility
Sortino ratio
Information ratio

Constraints:
No position >20% of portfolio.
Maximum portfolio drawdown target: 10%.
