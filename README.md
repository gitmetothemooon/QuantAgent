# QuantAgent
Build an explainable investment decision support system that generates transparent, risk-aware stock recommendations and demonstrates competitive long-term performance through disciplined portfolio management and rigorous backtesting.
A quantitative trading system built in Python for research, backtesting, paper trading, and explainable AI-assisted decision making.

## Project Goals

- Collect historical market data
- Generate technical indicators
- Backtest trading strategies
- Evaluate risk
- Support paper trading
- Produce explainable buy/sell recommendations
